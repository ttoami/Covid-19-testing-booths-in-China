# 項目簡介 Project Overview

本項目收錄了《核酸亭去哪了？------中國城市空間中的廢棄物、閾限憶景與新冠遺產》研究期間所拍攝的全部照片。

This project archives all photographs taken during the study *"Where Did the COVID-19 Testing Booths Go? Waste, Liminal Memoryscape, and the Pandemic Heritage in China's Urban Space."*
